# RevivePSVR1 - Statik v0.1.0

Initial Windows PCVR pre-release. Download **RevivePSVR1-Statik-v0.1.0-Windows-PCVR.zip**
from the assets below. It includes the ready-to-run player and package importer;
no compilation is required. The automatic "Source code" archives are for developers.

## Getting started

1. Extract the entire ZIP into a writable folder.
2. Put your own extractable Statik CUSA06929 base PKG in games (APP_VER 01.00,
   VERSION 01.01). No separate update is required.
3. Start your OpenXR headset runtime and open Play Statik VR.bat.

Requires Windows x64, a Vulkan-capable GPU with current drivers and the Microsoft
Visual C++ x64 runtime. No game, firmware or saves are included.

## Included

- OpenXR stereo rendering with headset field of view.
- PC DualShock/DualSense and tracked VR controllers, including Steam Frame bindings.
- Selectable tracked hand, mixed input and view/box recentering with L3 + R3.
- Rendering scale options of 100%, 125%, 150% and 200% for the supported game layout.
- Loading-memory and PROJECT stereo-stencil corrections.
- Optional Enhanced surfaces, off by default, and an in-game VR controls guide.
- Automatic package preparation with failure diagnostics and local log collection.

The packaged executable is the player accepted in a user headset smoke test on
17 October 2026. Full-game completion and every headset/controller combination
have not been verified. Known limitations include previously observed Vulkan
color-to-depth copy validation issues and incomplete Enhanced material coverage.
Higher rendering scales require more GPU power and memory.

For upgrades, back up pc-vr-tests/Statik/user before copying your existing user
folder into the new installation. For a bug report, run Collect PCVR Logs.bat
and review the archive before sharing it. See README.md and docs for details.
