# Saves and upgrades

Runtime data stays in `pc-vr-tests/Statik/user` for compatibility with earlier
standalone builds. Saves are under `home/1000/savedata/CUSA06929` within that folder.

Close the game and back up the entire `user` folder before upgrading. Copy your
old `user` folder into the same location in the new installation. Do not replace
old saves with an empty folder. Rebuilding the player does not remove user data.

The initial repository contains clean defaults only. No tester saves are imported.
