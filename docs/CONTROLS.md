# Controls

Use a PC DualShock 4/DualSense or a pair of OpenXR VR controllers. The launcher
lets you select which tracked hand positions the emulated gamepad. Automatic
input supports switching between PC gamepad and VR buttons; tracked pose and
PC button input can be used together.

## Recenter

- VR controllers: hold both comfortably in front of you, look forward and press
  both stick clicks (L3 + R3) without Menu. The view and virtual box recenter
  together; the current tracked orientation becomes level.
- PC gamepad: hold Options/Start for about one second to recenter the view and pad.

## Controllers with fewer buttons

Both thumbsticks normally remain analog. Hold Menu to use the left stick as
the directional pad and the right stick for the touchpad. Consult the replacement
in-game controls image for the full button map. Steam Frame retains its native
gamepad-style inputs instead of relying only on the reduced-button mapping.

Runtime/controller bindings still require device-specific testing. Include the
active OpenXR runtime and controller profile in any input bug report.
