STATIK PACKAGE PREPARATION

Put your own extractable Statik base PKG in games, then start Play Statik VR.bat.
The launcher scans games and checks package metadata. Renaming a file does not
change its title, version or contents.

Supported title: CUSA06929.
Supported base layout: APP_VER 01.00, VERSION 01.01.
No separate update is required for this layout.

Preparation keeps the original PKG. The launcher validates the result before
starting the game. A failed or incomplete extraction is not launched.
Use a writable local folder and make sure there is enough free space for the
original PKG and extracted game. Administrator access is not required.

If preparation fails:
- Read the message and the diagnostic log path shown by the launcher.
- Confirm the title/version, that the copy is complete and that the file is a
  PKG rather than a renamed archive. Encrypted store downloads are not supported.
- For access errors, check folder permissions and whether another process has
  locked the file. The extraction helper reads the original package without
  requiring write access to it.
- Keep the failure logs. The importer records the PKG SHA256 on failure so the
  exact package can be compared without sharing the package itself.
- Run Collect PCVR Logs.bat and review the resulting archive before sharing it.

Never distribute your PKG, extracted game files or saves with a bug report.
