# Contributing

Keep changes focused on Windows PCVR Statik. Use English for code comments,
documentation and user-facing text. Preserve upstream authorship and licenses.
Explain the observed problem, the changed behavior, and what was actually tested.
Do not infer playability from a single screenshot or a test stopped by a timer.

For rendering/input issues, provide headset, OpenXR runtime, controller model,
GPU/driver, resolution scale, Enhanced setting, level and reproduction steps.
Review support logs for personal information before attaching them. Never upload
game packages, keys, firmware, extracted assets or saves without an explicit need
and the right to distribute them. No automatic uploads are performed by this project.
